# 梯队规划智能体（Dify 网页版）

## 架构

```text
PlanningView.vue / ModuleAssistant
        -> /api/planning/ai/chat
talent-planning-service 读取并脱敏本地实时数据
        -> https://api.dify.ai/v1/chat-messages
Dify Cloud 工作流只负责自然语言分析与建议
```

Dify Cloud 无法访问本机 `127.0.0.1:9090`，所以本工作流没有 HTTP 节点。数据库访问、评分和风险规则仍由本地规划服务负责，Dify 不持有数据库账号。

## 网页版导入

1. 打开 <https://cloud.dify.ai/apps> 并登录。
2. 选择“创建应用” -> “导入 DSL 文件”。
3. 上传 `dify/talent-planning-agent.yml`。
4. 导入后打开“编排”，检查“梯队决策分析”节点的模型。如果账号没有 DeepSeek 模型权限，改为账号中任一可用聊天模型。
5. 发布应用。
6. 进入“访问 API” -> “API 密钥”，创建一个仅用于本应用的密钥。

## 本机配置

在启动规划服务的 PowerShell 中设置：

```powershell
$env:PLANNING_DIFY_BASE_URL = "https://api.dify.ai"
$env:PLANNING_DIFY_API_KEY = "app-你的规划应用密钥"
$env:SPRING_DATASOURCE_PASSWORD = "0721"
mvn spring-boot:run -pl talent-planning-service
```

不要把 API Key 写入 Git、前端代码或截图。修改环境变量后需要重启规划服务。

## 验证

```powershell
Invoke-RestMethod http://127.0.0.1:8082/api/planning/ai/status
Invoke-RestMethod http://127.0.0.1:9090/api/planning/ai/status
```

状态中的 `configured` 应为 `true`。然后打开 `http://127.0.0.1:5173/planning`，在页面底部使用“梯队规划智能体”。

推荐测试问题：

- 分析当前梯队整体健康度
- 找出继任风险最高的岗位
- 分析关键岗位的人才缺口
- 分析产品经理岗位的继任候选和技能短板
- 给出未来一个季度的梯队建设优先行动建议

智能体为只读助手。设置关键岗位、刷新候选、重新评估风险和处理预警仍需在页面中人工执行。
